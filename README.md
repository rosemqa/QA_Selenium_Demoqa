# UI testing of the DemoQA site for training QA engineers

This project is designed for automated UI testing of the [DemoQA site](https://demoqa.com/) using modern tools
and patterns. It includes tests that verify key user interactions with the website.

## Project Description

The project contains automated tests written in Python utilizing the following technologies and patterns:

- **Pytest** — testing framework for organizing and running tests
- **Selenium** — browser automation tool
- **Allure** — generating detailed and attractive test reports
- **Page Object Model (POM)** — for organizing page classes to separate test logic from page-specific interaction logic
- **Docker** — containerization of the testing environment
- **CI/CD** — automated test runs via GitHub Actions and GitLab CI/CD
